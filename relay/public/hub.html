The series: four workshops

  1. Workshop 1Signals

    Tell metrics, logs and traces apart, see how each one works, and use all three to find a live outage.

  2. Workshop 2API performance

    Latency the way users feel it, percentiles, N+1 and unselective queries, GraphQL, load tests.

  3. Workshop 3Web performance

    What the browser felt: LCP, INP and CLS at the room's p75.

  4. Workshop 4Before users notice

    SLOs and the nines, error budgets, alerts on what users feel, status pages.

Each workshop's room opens only while it runs. The demos, the slides and every term are open source at github.com/ofri-peretz/workshops.
